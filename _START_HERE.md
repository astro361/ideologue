## 🚨 Important Notes

### ⚠️ Before First Use

Users who clone your repository will need to:

1. Copy `.env.example` to `.env`
2. Generate `NEXTAUTH_SECRET`: `openssl rand -base64 32`
3. Get Google OAuth credentials
4. Set up PostgreSQL database
5. Run `npx drizzle-kit push`

**They have complete guides in the documentation!**

### 🔐 Security

- Your `.env` file is **NOT** committed (in `.gitignore`)
- Only `.env.example` is pushed (safe template)
- No secrets are hardcoded anywhere
- Google OAuth credentials in `.env` are YOUR secrets
- Users must get their own credentials
